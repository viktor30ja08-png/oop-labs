Лабораторна робота №1: Операції з матрицями
Реалізація базових операцій над двовимірними масивами типу int. Програма включає строгу валідацію вхідних даних (захист від "рваних" матриць), множення матриці на заданий скаляр та нестандартний алгоритм обходу для знаходження суми найменших елементів у кожному стовпці результату.

Лабораторна робота №2: Обробка рядків
Імітація мутабельного типу StringBuffer засобами Python (через масиви символів). Завдання полягає у розбитті тексту на слова без використання стандартного методу split() (реалізовано власний парсер) та подальшому сортуванні цих слів за зростанням кількості голосних літер.

Лабораторна робота №3: Класи та об'єкти
Основи ООП. Проєктування предметної області "Навчальний заклад" (EducationalInstitution). Програма створює масив об'єктів і виконує їх дворівневе сортування (рівень акредитації — за зростанням, кількість студентів — за спаданням) за допомогою лямбда-виразів. Також реалізовано пошук об'єкта за станом через перевизначений магічний метод __eq__.

Лабораторна робота №4: Відношення між класами (Композиція)
Глибока об'єктно-орієнтована архітектура на базі Принципу Єдиної Відповідальності (SRP). Текст проєктується як сувора ієрархія об'єктів: Текст -> Речення -> Слова/Пунктуація -> Літери. Додатково реалізовано метод очищення тексту, який замінює будь-які послідовності табуляцій та пробілів на одинарний пробіл.

Лабораторна робота №5: Наслідування та Поліморфізм
Проєктування ієрархії для предметної області "Ігрова кімната". Створено базовий клас іграшки (Toy) та специфічні дочірні класи (Car, Doll). Реалізовано клас-менеджер Playroom, який агрегує іграшки та забезпечує суворий контроль фіксованого бюджету (блокує додавання об'єктів при перевищенні ліміту). Також додано функціонал фільтрації та сортування іграшок за ціною.
